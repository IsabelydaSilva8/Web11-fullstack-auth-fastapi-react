# Sistema simples de autenticação Full-Stack(FastAPI + React)
  Este projeto faz parte de um estudo principalmente sobre a aplicação Full-Stack e a 
  framework FastAPI,e com um banco dados SQLite que cria o banco de dados no próprio 
  projeto e Bcrypt para criptografar e fazer hashing das senhas, assim iniciando com um 
  sistema simples mas com segurança de login e register.

# Tecnologias Utilizadas
*******Backend
* FastApi
* Python
* SQLite
* SQLAlchemy
* Bcrypt

******Frontend
* React
* TypeScript
* Vite
* Axios
* React Router 

# Como rodar o projeto
  Certifique-se de ter o **Python (3.12+)** e o **Node.js** instalados em sua máquina.
*******Backend
1. Entrar na pasta 'backend'
2. Crie e ative o ambiente virtual 'venv'
3. Para instalar as dependências no terminal digite: **pip install -r requirements.txt**
4. Para iniciar o servidor no terminal digite: **uvicorn main:app --reload**

******Frontend
1. Entrar na pasta 'frontend'
2. Para instalar as dependências no terminal digite: **npm install**
3. Para iniciar o app no terminal digite: **npm run dev**
